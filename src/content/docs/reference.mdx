## API overview

The API is a FastAPI service (`owload-backend`). The source of truth is the code and its README in [github.com/owload/owload-backend](https://github.com/owload/owload-backend); this page is a map.

<Aside type="note" title="What is, and is not, in the API">
Everything that reaches the API is **already encrypted by the client**. The API has no operation that takes a password, a key or a file name. So a script can use it to move bytes and manage access, but reading a drive's content needs the client's decryption.
</Aside>

### Authentication

Requests carry a Keycloak **access token** (a JWT) in the **`x-access-token`** header, not in `Authorization`. The API checks the signature against the realm's published keys, the issuer (`KEYCLOAK_ISSUER`) and the audience. There are no local accounts.

The routes under `/public/<token>` need no token.

### Routes

| Prefix | What it is for |
|---|---|
| `GET /healthz` | Health check. |
| `/userinfo` | The signed-in user's profile, plan usage, devices and activity. |
| `/drives` | List, create, read and delete drives; the drive's description, storage limit. |
| `/drives/{id}/access` | Visibility, people and roles, the public link. |
| `/drives/{id}/access-request` | Ask for access to a drive you are not on. |
| `/drives/{id}/storage-targets` | A drive's storages: add, make main, remove, test connection. |
| `/drives/restore` | Find and restore drives from a bucket. |
| `/ops/{driveId}` | Read the encrypted operation log, and append to it at a stated position. |
| `/sessions` | Reserve room for an upload, and finish it. |
| `/data` | Write, read and free ranges of the drive's data. |
| `/s3-presets` | List the storages the operator offers; test one. |
| `/public/{token}` | Read-only access to a public drive: its info, log and data. |

### Conventions

- **Byte ranges, not files.** The data area is addressed by absolute byte offsets; a file is just a range that the client keeps track of in its encrypted log.
- **Sessions reserve, then write.** An upload reserves a range with `POST /sessions`, writes blocks at offsets inside it, and finishes the session.
- **Errors are plain.** A drive that is not found and one you may not see give the same `404`. A refused upload because of a limit is `413` with the code `STORAGE_LIMIT_EXCEEDED`; a storage problem is `502` with a fixed set of reasons and no storage details.
- **Rate limits** apply to public reads, per client address, so that a link cannot be used to hammer the server.

For the exact request and response bodies, read the [backend README](https://github.com/owload/owload-backend) and the OpenAPI description FastAPI generates for the running service.

## Limits

The limits of the **hosted** Owload. On a [self-hosted](../self-hosting/) installation the operator sets the ones marked *configurable*.

### Storage

| | Limit |
|---|---|
| Free plan, on Owload's storage | **3 GB** *(configurable)* |
| Your own S3 | No limit from Owload |
| Limit of a single drive | Optional, set by the owner |
| Storages per drive | **1 main + up to 2 secondary** |
| Block size | **1 MiB** |
| Time an unfinished upload holds its reserved room | **24 hours** *(configurable)* |

### Files

| | Limit |
|---|---|
| Any file | Stored and downloaded; no size limit of its own, only your storage limits |
| Text file opened in the editor | **10 MiB**, UTF-8 |
| Spreadsheet opened in the editor | **100 MiB** |
| Video buffer in the browser | up to **2 GiB** of encrypted pieces |
| Thumbnails | 360 px for the grid, 1024 px for large previews |
| Profile picture | PNG, JPEG or WebP |

### People and drives

| | Limit |
|---|---|
| Roles | reader, writer, admin (and the owner) |
| Readers shown on a drive's card | the **12** most recent |
| Faces shown in a drive's access summary | **5** people (all of them are counted) |
| Drives found in one **restore** scan | **100** |
| Drives restored in one go | **20** |

### Retention

| | Kept for |
|---|---|
| Account activity | **365 days** *(configurable)* |
| Signed-in devices not used | 90 days |
| Visits to a public drive | 30 days |

### Rate limits

Reads through a **public link** are limited per client address (600 requests a minute on Owload *(configurable)*), so that a link cannot be used to overload the server. Past it, the server answers "too many requests"; wait a minute.

## Glossary

**Account.** Your sign-in: an email and a password at the sign-in service. It identifies you. It does **not** unlock your drives.

**Admin.** A role on a drive: everything a writer can do, and manage people and access. Only the owner makes admins.

**AI Guard.** An AI agent that watches Owload's server and its logs for anything suspicious. See [Security and AI Guard](../security/#security-and-ai-guard).

**Block.** A 1 MiB piece of a drive's encrypted data. A storage holds a drive as blocks.

**Bucket.** A container in an S3 storage. A drive's data lives in a bucket.

**Ciphertext.** Encrypted data: unreadable without the key. It is all that Owload's servers store.

**Custom (storage).** Your own S3, entered by hand when you create a drive or add a copy, as opposed to a **preset**.

**Drive.** A place for files and folders, with its own password, storage and access. See [Drives](../using-drives/#drives).

**Drive password.** The secret you set for a drive. The drive's keys are made from it on your device. It cannot be recovered or reset.

**Key.** A secret number that encrypts and decrypts. Owload's keys are made from your drive password, on your device, and never leave it.

**Link (public).** An address that opens a **public** drive. It does not carry the drive's password.

**Log (the drive's).** The encrypted, append-only record of everything done in a drive: it is how the client knows what files there are.

**Main storage.** The storage a drive is read from. A drive may also have up to two **secondary** storages that hold copies.

**Owner.** The person who created a drive. Only they can delete it, set its limit and make admins.

**Preset.** A storage that Owload (or the operator of a self-hosted installation) offers to everyone who creates a drive.

**Public drive.** A drive that anyone with its link **and** password can read, without an account. Read-only.

**Reader, writer.** Roles on a drive. A reader views and downloads; a writer also changes files.

**S3.** The standard way of talking to object storage, used by AWS S3 and many other services and servers.

**Secondary storage.** A storage that holds a copy of a drive. See [Copies in more than one storage](../storage/#copies-in-more-than-one-storage).

**Self-hosted.** Owload run on your own server. See [Self-hosting](../self-hosting/).

**Shared drive.** A drive that its owner opened to named people, each with a role.
